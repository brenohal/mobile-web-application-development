**PHP · Java/JSP · Android · Responsive UI**

Course projects from LIS 4381 at Florida State University, spanning mobile interface design and server-side web development. The two projects below show the most complete applications in the repository.

## Project 2 · Pet Store Admin

A PHP and MySQL application for viewing, adding, editing, and deleting pet store records. It uses server-side validation and prepared statements for database operations, and presents records in a searchable, sortable table.

## More coursework

The repository also includes Android and Java/JSP exercises, responsive layouts, form validation, and file and database operations. Work is grouped by assignment (`a1/`–`a5/`) and project (`p1/`, `p2/`).

## Run locally

The business card and Pet Store Admin are PHP applications. Project 2 also needs MySQL and the database configured for the connection settings in `global/connection.php`. The repo does not include a single setup script, so configure a local PHP/MySQL environment before serving the project.
